# Alive Controller

A VEX IQ controller in your browser for the robot **WinterB** (77718W Winterbots).

- 3D VEX IQ controller and Brain you can click, drag and pick up
- Keyboard driving (WASD + arrows), drive modes, power = Bluetooth on/off, lock-controller view
- Connects to the robot over Web Bluetooth (Chrome or Edge), with a 4-digit pairing code
- Follow me: the robot drives to your camera and stops 10 inches away

Open it at the GitHub Pages address of this repository in Chrome or Edge.
The robot runs the WinterB receiver program (Robot log → Show Brain program on the site).

Fan-made. Not affiliated with VEX Robotics or Innovation First. 3D models converted from VEX's public CAD files.
Built with React, three.js and components from React Bits.
